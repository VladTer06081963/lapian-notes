## 1. Текущее состояние подсистемы локализации (i18n)

1. **Поддерживаемые языки:**
   - На данный момент в `src/i18n/core.ts` поддерживаются только два языка:
     - `zh-CN` (упрощенный китайский — канонический язык интерфейса и данных)
     - `en` (английский — перевод через каталог `src/i18n/catalog.en.ts`)
2. **Архитектура i18n:**
   - Перевод интерфейса осуществляется динамически через обход DOM-дерева (`MutationObserver`) и текстовый каталог.
   - Механизм сопоставления: точное совпадение ключа + динамические шаблоны с интерполяцией `${...}`.
   - Защита пользовательского контента: атрибуты `data-i18n-ignore` и специальные токены `__LAPIAN_AUTHORED_TEXT_`.
   - Экспорт документов (`markdown.ts`, `framePackage.ts`) принимает параметр `locale: Locale = 'zh-CN'`.
3. **Объем каталога:**
   - В каталоге `src/i18n/catalog.en.ts` содержится ровно **951 запись** (213 из них содержат динамические плейсхолдеры `${...}`).
4. **Тесты и верификация:**
   - Набор тестов `npm test` покрывает:
     - Нормализацию локали (`tests/i18n/core.test.ts`)
     - Границы перевода (`tests/components/i18n-boundaries.test.ts`)
     - Генерацию локализованного Markdown и пакетов (`tests/i18n/generated.test.ts`, `tests/lib/markdown-localization.test.ts`)
   - Скрипт `scripts/audit-i18n.mjs` проверяет целостность каталога `catalog.en.ts` и паритет плейсхолдеров.

## 2. Необходимые изменения для поддержки русского языка (`ru`)

1. **Типизация и нормализация (`src/i18n/core.ts`):**
   - Расширение типа `Locale`: `'en' | 'ru' | 'zh-CN'`.
   - Поддержка распознавания префиксов `ru` и `ru-*` в функциях `normalizeLocale` и `detectLocale`.
2. **Каталог перевода (`src/i18n/catalog.ru.ts`):**
   - Создание полного каталога русской локализации с 951 ключом.
   - Строгое сохранение всех динамических плейсхолдеров `${...}` без изменений.
   - Использование точной кинематографической терминологии (*раскадровка*, *таймлайн*, *сюжетные линии*, *кривая эмоций зрителя*, *дерево структуры*).
3. **Маршрутизация перевода (`src/i18n/translate.ts`):**
   - Подключение `russianCatalog` и создание переводчика `translateRussian`.
   - Обработка `locale === 'ru'`.
4. **Интерфейс переключения языка (`src/i18n/index.tsx`):**
   - Добавление опции `<option value="ru">Русский</option>` в компонент `LanguageSwitcher`.
5. **Тесты и скрипты аудита:**
   - Добавление тестов на локаль `ru` в `tests/i18n/core.test.ts`.
   - Проверка успешного прохождения `npm run check`.
