## 2. Описание проблемы: Ошибочная идентификация персонажей нейросетью
При автоматическом анализе фильма нейросеть (включая мультимодальные модели) сталкивается с нехваткой сценарного контекста при разборе кадров и субтитров:
1. **Подмена персонажей и родов:**  
   Нейросеть ошибочно определяет мужского персонажа как женщину (или наоборот), либо использует обезличенные описания (*«женщина»*, *«незнакомка»*, *«девушка»* вместо конкретного персонажа, например, *«Шура Балаганов»*).
2. **Трудоёмкость ручного исправления:**  
   Упоминания персонажа разрознены по множеству полей структуры [`Segment`](file:///Users/mac/lapian-notes/src/types.ts#L47):
   - `title` (заголовок эпизода);
   - `screenplayDraft` (черновой текст сценария);
   - `screenplayBlocks` (структурированные блоки: действия, реплики, ремарки);
   - `keyBeats` (ключевые биты сюжета с таймкодами);
   - `segmentFunction` (функция сцены);
   - `creativeIntent`, `audienceExperience`, `notes`;
   - глобальный `macroAnalysis` (логлайн, арки персонажей).
3. **Неприменимость простого Find & Replace:**  
   Прямая замена подстроки ломает текст на русском языке:
   - **Род глаголов прошедшего времени:** *«сказала»* $\rightarrow$ *«сказал»*, *«пошла»* $\rightarrow$ *«пошёл»*, *«удивилась»* $\rightarrow$ *«удивился»*.
   - **Местоимения:** *«она»* $\rightarrow$ *«он»*, *«её»* $\rightarrow$ *«его»*, *«ей»* $\rightarrow$ *«ему»*, *«с ней»* $\rightarrow$ *«с ним»*.
   - **Склонение имени персонажа:** *Шура Балаганов*, *Шуры Балаганова*, *Шуре Балаганову*, *Шуру Балаганова*.
   - **Контекстная неизбирательность:** если в фильме действительно присутствуют другие женские персонажи, «слепая» замена испортит их описания и реплики.

## 3. Решение: Специализированный MCP-сервер (`lapian-notes-mcp`)
Для решения этой проблемы разрабатывается MCP-сервер (Model Context Protocol), позволяющий подключить AI-ассистента напрямую к структуре проекта `lapian-notes` для выполнения умных пакетных правок.

### Архитектура MCP-сервера:
- **Стек:** TypeScript / Node.js с использованием официального `@modelcontextprotocol/sdk`.
- **Расположение:** `tools/mcp/` внутри репозитория `lapian-notes`.
- **Типизация:** Прямое переиспользование существующих TypeScript-типов проекта ([`Project`](file:///Users/mac/lapian-notes/src/types.ts#L1), [`Segment`](file:///Users/mac/lapian-notes/src/types.ts#L47), [`ScreenplayBlock`](file:///Users/mac/lapian-notes/src/types.ts#L101)).

### Набор инструментов (MCP Tools):
1. **`get_project_data`**: Чтение JSON-файла проекта, валидация схемы и возврат метаданных (таймлайн, список персонажей, количество эпизодов).
2. **`scan_entity_mentions`**: Семантический поиск всех вхождений указанной сущности/персонажа по всем полям эпизодов с фильтрацией по таймкодам или сценам.
3. **`preview_character_replacement`**: Формирование diff-отчёта с грамматически согласованными заменами (роды глаголов, падежи, местоимения) до внесения изменений.
4. **`apply_character_replacement`**: Применение согласованных правок к файлу проекта с сохранением валидности JSON и структуры таймлайна.
5. **`validate_project_integrity`**: Проверка целостности связей эпизодов, кадров и схемы после модификации.
