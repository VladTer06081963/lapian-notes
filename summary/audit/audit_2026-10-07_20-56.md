# Аудит: Интеграция MiniMax и поддержка .env для AI API ключей (2026-10-07 20:56)

## 1. Текущее состояние
- В проекте реализован механизм прямого обращения к AI-моделям (BYOK) через OpenAI-совместимый протокол `/chat/completions` с локальным Vite-прокси `ai-proxy-server-plugin.ts`.
- В списке предустановленных провайдеров (`DIRECT_AI_PROVIDERS` в `src/lib/directAi.ts`) присутствовали Gemini, Kimi, OpenAI, Claude и Custom.
- Ключи API сохранялись только в `localStorage` браузера пользователя; отсутствовала загрузка ключей из `.env`/переменных окружения и документация по ключам провайдеров.

## 2. Потребность пользователя
- Добавить провайдер **MiniMax** в список предустановленных провайдеров прямо в коде (`DIRECT_AI_PROVIDERS`).
  - Base URL: `https://api.minimax.io/v1`
  - Базовая модель: `MiniMax-VL-01` (мультимодальная модель с поддержкой анализа кадров и зрения)
  - Поддержка переключения в текстовый режим (`MiniMax-Text-01` / `MiniMax-M3.1-Flash-Preview` при отключенной опции раскадровки).
- Вынести API-ключи в `.env` (и `.env.example` как шаблон) для удобного заполнения пользователем:
  - `MINIMAX_API_KEY` (а также `VITE_MINIMAX_API_KEY` / поддержка других провайдеров: `GEMINI_API_KEY`, `OPENAI_API_KEY`, `CLAUDE_API_KEY`, `KIMI_API_KEY`).
  - Передача ключей в клиентское приложение через `define` в `vite.config.ts` с помощью `loadEnv`.
  - Fallback в прокси-сервере dev-окружения (`ai-proxy-server-plugin.ts`) на переменные `process.env`.
  - Автоматическое предзаполнение ключа из `.env` в модальном окне `DirectAiModal` при выборе соответствующего провайдера.

## 3. План реализации
1. Обновить `vite.config.ts` для использования `loadEnv` и внедрения переменной `__AI_ENV_KEYS__`.
2. Добавить типизацию `__AI_ENV_KEYS__` в `src/vite-env.d.ts`.
3. Обновить `src/lib/directAi.ts`:
   - Добавить провайдера `minimax` в `DIRECT_AI_PROVIDERS`.
   - Реализовать функцию `getEnvApiKey(providerId)` и автоподстановку ключей из окружения.
   - Обеспечить раздельное сохранение/запоминание ключей для каждого провайдера в `DirectAiConfig`.
4. Обновить `src/components/DirectAiModal.tsx`:
   - Поддержка отображения и предзаполнения ключей из `.env`.
   - Индикация наличия ключа в `.env` в плейсхолдере.
5. Обновить `ai-proxy-server-plugin.ts`:
   - Добавить fallback на `process.env` для ключей при запросах к соответствующим эндпоинтам/моделям.
6. Создать `.env.example` с описанием и шаблонами ключей всех провайдеров и дополнить `.env`.
7. Написать тесты и запустить полный пайплайн проверок (`npm run check`).
8. Обновить `changelog.md`.
