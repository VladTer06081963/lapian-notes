# Changelog (Журнал изменений)

## [Unreleased] - dev

### 2026-10-07 22:55 (+03:00)
- **Полное отключение китайского языка и установка русского языка по умолчанию:**
  - Удален китайский язык (`zh-CN`) из переключателя `LanguageSwitcher` в `src/i18n/index.tsx` (доступны только «Русский» и «English»).
  - Добавлена автоматическая миграция `localStorage`: при наличии сохраненной ранее локали `zh-CN` значение автоматически перезаписывается на `ru`.
  - В `src/i18n/core.ts` дефолтная локаль изменена на `ru` (`DEFAULT_LOCALE = 'ru'`), в алгоритме детекции `detectLocale` старый китайский язык прозрачно сменяется на русский.
  - Метка провайдера `自定义` в `src/lib/directAi.ts` переведена на «Пользовательский».
  - В `src/i18n/catalog.ru.ts` заменены оставшиеся китайские токены: ««推进»» -> «Развитие», «剧情线» -> «сюжетную линию».
  - В инструкциях генерации промпта для AI (п. 10 и п. 7 в `catalog.ru.ts`) жестко зафиксировано требование вывода всех описательных полей и типов блоков на русском языке.
  - Обновлены тесты локализации в `tests/i18n/core.test.ts`. Все 65 тестов, аудит i18n, линтинг и сборка `npm run check` успешно пройдены.


### 2026-10-07 21:00 (+03:00)
- **Интеграция провайдера MiniMax и поддержка .env для AI API ключей:**
  - Добавлен провайдер `MiniMax` в список предустановленных провайдеров прямого подключения (`DIRECT_AI_PROVIDERS` в `src/lib/directAi.ts`) с базовым URL `https://api.minimax.io/v1` и моделью по умолчанию `MiniMax-VL-01` (мультимодальная модель с анализом раскадровок).
  - Реализован механизм чтения ключей из переменных окружения (`.env` / `.env.local`) через Vite `loadEnv` и инъекцию `__AI_ENV_KEYS__` в `vite.config.ts`.
  - В `src/lib/directAi.ts` реализована функция `getEnvApiKey()` и изолированное сохранение ключей для каждого провайдера (`providerKeys`), исключающее затирание ключей при переключении между провайдерами.
  - В модальном окне `DirectAiModal.tsx` добавлена автоподстановка ключа из `.env` и визуальная подсказка в плейсхолдере.
  - В dev-серверном прокси `ai-proxy-server-plugin.ts` добавлен fallback на системные переменные `process.env`.
  - Создан файл `.env.example` с шаблонами для MiniMax, Gemini, Kimi, OpenAI и Claude; обновлен локальный `.env`.
  - Добавлены модульные тесты в `tests/lib/direct-ai.test.mjs`; все 64 теста пройдены успешно.
